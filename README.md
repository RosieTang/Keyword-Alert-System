# Keyword-Alert-System
A Realtime GitHub keyword monitoring and notification system.

# Get Started
## 1. Copy env and fill in your values
cp .env.example .env

## 2. Apply DB schema
npm run db:setup

## 3. Install deps
npm run install:all

## 4. Start backend (terminal 1)
npm run dev:backend

## 5. Start frontend (terminal 2)
npm run dev:frontend
